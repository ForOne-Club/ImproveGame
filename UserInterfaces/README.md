# UserInterfaces 文件夹说明

## 背景

本项目原本的 UI 框架直接内置于模组中，现计划迁移至 **SilkyUI**。
为清晰区分新旧代码，所有使用 SilkyUI 编写的新 UI 将统一放置于本文件夹（`UserInterfaces`）下。

## 维护策略

- **旧版 UI**：不再进行大规模功能更新，仅修复严重 BUG。
- **新版 UI**：后续主要的功能迭代与界面优化，均在本目录下基于 SilkyUI 实现。

---

# SilkyUI & ImproveGame 设计规范

## 基本规则

### 尺寸单位
**必须遵守**：所有尺寸（宽、高、边距等）必须为 **2 的倍数**。

### 间距规范
- **小面板**：4 像素

## Header 规范（小面板）

- **高度**：36 像素
- **字体**：大号
- **字体大小**：0.4
- **控制按钮**：须使用与当前“增益控制器”相同风格的贴图资源。

## 配色方案

- **底框边框色**：`SUIColor.Border`
- **底框背景色**：`SUIColor.Background * 0.75`
