### 为何创建这个文件夹

因为原来使用的 UI 框架直接在模组内部，现在要迁移至 SilkyUI。\
为做区分，所以将使用 SilkyUI 创建的新的 UI 放置在 UserInterfaces 文件夹下。

旧版 UI 不再做大型内容更新，仅进行 BUG 修复。

后续 UI 主要更新调整将在这个目录下使用 SilkyUI 编写的 UI 上进行

# SilkyUI & ImproveGame 风格设计规则

## 必须遵守

任何尺寸必须是 2 的倍数

## 任何间距

小面板：4

## Header 规范

小面板：36
字体：大号
字体大小：0.4
控制按钮：只能使用同现在增益控制器相同风格贴图

## 配色

底框边框色：SUIColor.Boreder
底框背景色：SUIColor.Background * 0.75
