## Additions

- Added two keybinds to quickly copy items' internal names
- New keybind for instant shimmer access
- Added toggle for auto-depositing specific currencies when money auto-deposit is enabled
- Introduced "Infinite Wire" feature

## Bug Fixes

- Fixed multiplayer fishing machine occasionally catching incorrect items or not applying accessory bonuses
- Fixed Shell Ship In Bottle usability issue
- Prevented Locator duplication in multiplayer
- Resolved config center search matching failures
- Fixed potential crash caused by "Pumpkin Grows Faster" feature recursion
- Addressed construction UI crash when renaming unnamed structures

## Adjustments

- "Display Debug Data" now shows item internal names
- Shell Ship In Bottle available in Shop Expand mod
- Enhanced Locator descriptions for clarity
- Aether Locator now detects Shimmer liquid without stored coordinates
- Crafting/purchasing rules updated for Shell Ship In Bottle, Locator, and Weather Book
- Revamped Locator activation to throw-and-break mechanic with visual effects
- Optimized config center search with fuzzy matching algorithm
