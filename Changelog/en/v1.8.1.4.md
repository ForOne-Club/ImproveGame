## Additions

- Added a new Storage Manager search keybind. Hover on an item and press this key to search for it

## Bug Fixes

- Fixed incorrect popup notifications of some Locators
- Fixed an issue where Calamity arena candles could all take effect as Portable Buff Stations, which only works for one at a time in Calamity
- Fixed an issue where items could not be properly retrieved from the Quick Shimmer when auto-pause was enabled
- Fixed potential conflicts with InventoryTweak or other mods
- Fixed Wand of Technology getting unfavorited when switching work modes
- Fixed the Storage Manager incorrectly displaying "Chest being used" in singleplayer
- Fixed an issue where bags would disappear when opening certain grab bags in Big Backpack

## Adjustments

- Improved the search bar UI of the current mod
- Added mod item settings back to the Config Center
- Remove the link in Auto-Generated Config Center and modified the description to emphasize that those Config Centers are auto-generated
- Improved toggle animation of side UIs, now will interact with mouse cursor during the animation
- Added "Refresh Shop" button to the Luiafk Reborn's Travelling Merchant
- QoT mod items won't be disabled via "Vanilla Enjoyer" preset anymore
- Minor UI adjustments
