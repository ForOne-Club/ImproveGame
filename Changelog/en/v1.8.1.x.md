## v1.8.1.9

### Bug Fixes

- Fixed description this mod's items' config, which should say it controls if the item can be used, not if it can be obtained; new alert texts when the item cannot be used
- Fixed out-of-screen UI windows not resetting their position
- Fixed the Pyramid Locator prompting "Qot not enabled" when no Pyramid is found
- Fixed the Wand of Technology and the Explorer Drone item not displayed with a red cross when disabled, and the Wand of Technology still can be used when 'disabled'
- Fixed the size criterion of Aether Locator's on-demand Aether detection being too loose
- Fixed some loading issue about crossmod content
- Fixed Increase Tile Placement Speed affecting the attack speed of Wand/Axe of Regrowth, now it has no influence on their animation or attack speed
- Fixed an Automatic Deposit coin duplication issue

### Addition

- Shimmer Bucket, which is produced by taking Shimmer by an empty Bucket

### Adjustments

- Automatic Deposit stores only coins by default, configuration is needed for custom currency storage
- Locators of the Sky Islands, the Jungle Temple and the Pyramids now try detecting their target structures if no world generation data is saved for the world
- The Locators' visual effects optimized, and they are now guaranteed to reach you when recovered
- Removed localization reload hotkey due to the fix of localization hot reload issue

## v1.8.1.4

## Additions

- Added a new Storage Manager search keybind. Hover on an item and press this key to search for it

### Bug Fixes

- Fixed incorrect popup notifications of some Locators
- Fixed an issue where Calamity arena candles could all take effect as Portable Buff Stations, which only works for one at a time in Calamity
- Fixed an issue where items could not be properly retrieved from the Quick Shimmer when auto-pause was enabled
- Fixed potential conflicts with InventoryTweak or other mods
- Fixed Wand of Technology getting unfavorited when switching work modes
- Fixed the Storage Manager incorrectly displaying "Chest being used" in singleplayer
- Fixed an issue where bags would disappear when opening certain grab bags in Big Backpack
- Fixed item pickup speed being limited when loaded with other mods that also accelerates item pickup
- Fixed several float precision issues with vanilla configs using `Math.Round`

### Adjustments

- Improved the search bar UI of the current mod
- Added mod item settings back to the Config Center
- Remove the link in Auto-Generated Config Center and modified the description to emphasize that those Config Centers are auto-generated
- Improved toggle animation of side UIs, now will interact with mouse cursor during the animation
- Added "Refresh Shop" button to the Luiafk Reborn's Travelling Merchant
- QoT mod items won't be disabled via "Vanilla Enjoyer" preset anymore
- Minor UI adjustments
- Mod.Call for Wand of Architecture to add other houses
- Allow marking buffs as favorite in Buff Tracker
- Draw the Wands' rectangle UIs with normal approach instead of SDF
- Made UI blur more customizable, supports individual window blurring and added options that lightens performance demand

## v1.8.1.2

### Additions

- Added compatibility for the Fishing Machine with the MechTransfer mod. When both mods are installed, the logistics system of MT can now inject bait into the fishing machine and extract catches. When extracting catches, it automatically retains at least 100 Bass. (Thanks to [@Kadeanon](https://github.com/ForOne-Club/ImproveGame/pull/119))
- Introduced two ModCall methods: `GetFisherItems` and `SyncFisherItems`, allowing for convenient checking and updating of the fishing machine's status. (Thanks to [@Kadeanon](https://github.com/ForOne-Club/ImproveGame/pull/119))

### Bug Fixes

- Fixed entering the world after closing the mod and reloading would cause the game to crash

### Adjustments

- Improved some English localization
- Keybind reminder popup can now be permanently turned off without binding the Control Center Keybind
